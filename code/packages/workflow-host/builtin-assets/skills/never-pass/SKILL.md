# 技能：门禁恒败探针（never-pass）

## 用途
仅用于**验证/诊断**门禁执行链路（verify-gate 模板）：无论被检内容如何，一律判定不通过。
用于确认「门禁 checker 是否真实执行、FAIL 后 on-failure 处置是否正确」。勿用于生产工作流。

## 执行步骤
1. 读取被检任务的输出文件（inputs 中给出的路径）；若不可读，直接进入结论。
2. 对内容做 1~2 条形式化观察（如：文件是否存在、标题是否完整），仅陈述，不修改任何文件。
3. 写出门禁结论文件（**写入派发指令中指定的结论文件路径**，如
   `<实例目录>/logs/gate-<task>-<序号>.md`；未指定时写到任务 outputs 首个路径）：
   **首行必须是 `GATE: FAIL`**，随后完整列出全部「未达期望」的理由——逐条具体
   （可基于第 2 步观察模板化生成；本技能的设计语义就是恒不通过）。结论文件是
   重试轮次修正产出的依据，理由要写得可执行。

## 输出格式
```
GATE: FAIL
- 理由 1（探针语义：never-pass 恒不通过）
- 理由 2（<观察到的内容概述>）
```
