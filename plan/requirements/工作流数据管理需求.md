## 一、预定义目录与安装（R1-R4）

**R1 预定义目录**：workflow_agent 插件包部署到 DSH 时创建自身运行所需目录，存放随包发布的模板、技能、样例、文档。目录为 **DSH 用户级全局唯一**（所有工作区共享，不做工作区本地覆盖），任何编排会话可访问，其他会话可读。

**R2 手工扩充**：用户可手工添加工作流定义、技能等文件到预定义目录，编排会话立即可用。

**R3 创建下拉**：创建工作流弹窗的下拉列表列出预定义目录中**全部**工作流（随包预置 + 用户添加）。

**R4 实例创建即复制定义**：创建实例 = copy 定义文件产生实例定义文件（instance.yaml）；**技能文件不复制**，各实例共用预定义目录技能。实例定义文件所在目录是否作为技能执行目录——**维持 workspace 为工作目录**（见 R22），技能资源查找采用开放点 1 折中方案（见 R21a）。实例级技能 copy 编辑留待后续版本（需考虑技能依赖技能情形）。

**路径解析规则（全局）**：各类文件引用（技能/输入/items 文件等）均支持相对路径与绝对路径；相对路径解析链 = **workspace 为根优先 → 找不到再回退预定义目录**。

## 二、工作流定义与实例编辑（R5-R14）

**R5 实例属性编辑**：实例创建后可在 workflow 页签编辑实例文件属性，变更只作用于本实例，不影响预定义目录文件。

**R6 编辑范围**：实例名称、总并发数量、工作流级 **params（简单键值表，数量有限）**；各任务的 input 文件路径、output 文件路径、process 技能（下拉选择）、gateChecker 技能（下拉选择）、门禁重试次数、并发数量。

**R7 结构级编辑（低优先级，延后）**：实例文件全文编辑、增删任务节点、调 dependOn、另存为模板到预定义目录——后续版本。

**R8 语义校验**：提供实例校验功能，检查：引用技能存在（预定义目录+workspace）、输入文件存在（workspace 文件或上游 output）、前后任务输入输出衔接、dependsOn 正确性（闭环/无环）等。

**R9 启动后禁编辑**：运行中的实例不允许编辑；编辑入口**可见但禁用**（提示"运行中不可编辑"）。

**R10 停止后编辑（延后）**：停止实例的未执行任务属性编辑——**本轮不做**（存在"重入 vs 清理产物"二择一未决，未来可能两种都要、可配置）。

**R11 任务技能指定**：任务未指定技能时，用户须在编辑界面**从下拉选择已有技能**；无合适技能时现场编写指令——**保存为预定义目录 skills/ 下的新技能文件**（可复用，不存实例目录）。（原需求"仅保存实例目录"语义已修订）

**R12 输入约束**：任务 input 必须是 workspace 中已存在的文件，或上一个任务的 output。

**R13 输出可缺省**：任务的 output 可以不设置。

**R14 门禁指定**：gateChecker 可不指定；指定时从下拉选择已有技能，或现场编写门禁指令（同 R11，保存为预定义目录技能）。

**编辑界面形态**：DAG 页**下方双栏**——左侧任务列表（类型/状态），右侧选中任务属性表单；顶部实例级字段。DAG 图初期**只读**（图元点击快速定位可后置）。实例管理（列表/下载/删除/归档）入口=**新增子页签**。技能下拉**优先实现**（扫预定义 skills/）；"自定义编写技能"列降级后置。

**名称语义**：实例名称为第一展示字段（列表/DAG 显示名称+ID）；instanceId 永不变。

## 三、执行期数据存储与传递（R15-R20）

**R15 文件交互**：任务间通过文件交互数据，后续任务需读取的数据必须落盘。

**R16 门禁输入**：任务的 inputs 与 outputs **全部**传递给本任务的门禁检查过程。

**R17/R18 items 提取（foreach/并发共用规则）**：items 来自指定文件——可以是 workspace 已有文件或上一个任务的 output。提取规则：**显式声明格式优先（`items-format`），缺省按扩展名推断，再缺省行文本（向后兼容）**。支持格式：
- **markdown**：列表项、**表格行**（每行=item，列名即字段名）；
- **JSON/YAML**：数组、并列对象（含 JSON Lines 式逐行对象）。

**对象 item 的注入语义**：`${item}` 默认优先取 **ID 或编号字段，其次名称字段**，都没有则按默认顺序编号；`${item.字段名}` 仅对提供了字段名的表格行/JSON/YAML 对象生效（供路径等标量注入）。

**R19 自由文件**：未被 output 指定的过程文件不限制、不管理，由用户负责。

**R20 目录变量**：引擎在解析展开期注入 `${workspace}`（工作区绝对路径）、`${wf_dir}`（工作流实例目录绝对路径）、`${skills}`（预定义技能根目录）、`${skill_dir}`（当前任务技能目录），语法与 `${param}`/`${item}` 同一注入正则。

## 四、技能（R21-R22）

**R21 技能形态与兼容**：技能以文件夹形式保存在预定义目录中（SKILL.md + 运行所需脚本/样例等文件）；frontmatter 的 name/version 供清单展示。**不兼容** OpenCode/Claude 特有的工具与指令。

**R21a 技能资源查找（开放点 1 折中定案）**：两者并存——
- 兼容层：派发时自动在子会话 prompt 附加一行"本技能全文来自 `<技能目录绝对路径>`"（不改技能文本，第三方技能零改动可用，把技能位置从推断变为明示）；
- 显式层：`${skill_dir}`/`${skills}` 变量供自家技能显式引用。

**R21b 外部 Agent（预留）**：需要 OpenCode/Claude 特有能力时，倾向启动外部 Agent 作为子执行体——落点=schema 已预留的 `external-agent` 任务类型（协议/派发待后续迭代实现）。技术边界事实：DSH 子会话可嵌套（树），但控制通道仅限直接父子（跨层注入被拒，只能 interrupt）。

**R22 执行工作目录**：技能执行以当前 workspace 作为工作目录；技能对路径有要求须在指令中明确，否则依赖 Agent 自身判断查找。

**技能清单展示**：下拉只列**名称+版本**（metadata 有版本才显示）；描述不默认展示（文字量不可控），浮动卡片可后置。

## 五、实例数据归档与管理前台（R23-R25）

**R23 实例列表**：实例管理子页签提供本工作区全部实例列表，分**活动实例 / 归档实例**两段；列=名称、ID、状态（阶段+派生）、孤儿标记、任务进度、创建时间。

**R24 打包下载**：允许多选实例**打一个 zip 包**下载（包内按实例分目录）；实例目录下所有内容都打包；非实例目录引用的文件不打包。

**R25 删除**：允许删除实例（含归档段），删除前数据丢失提醒；**RUNNING 不允许删除**；删除时**自动解绑会话**。
