# 设计评审 Gate

## 指令

你是一个设计评审专家。请评审需求分析结果，逐项检查：

### 检查项

1. **完整性**：是否覆盖了需求文档中的所有功能点？每个功能需求是否编号为 FR-XXX？
2. **准确性**：每个 FR/NFR 的描述是否与原文一致？有无误解或遗漏？
3. **NFR 归类**：非功能需求是否按正确类别归类（性能/安全/兼容性）？
4. **隐含假设**：是否识别了至少一个隐含假设？
5. **模糊点**：是否标注了需求中模糊或不清晰的地方？

### 判定规则

- 5 项全部通过 → **PASS**
- 任一项不通过 → **FAIL**，列出具体不通过项和改进建议

### 输出格式

将结果写入 `PoC/output/gate-result.md`：

```markdown
## 门禁结果: PASS / FAIL

### 详细检查
| 检查项 | 结果 | 说明 |
|--------|------|------|
| 完整性  | ✅/❌ | ... |
| 准确性  | ✅/❌ | ... |
| NFR归类 | ✅/❌ | ... |
| 隐含假设 | ✅/❌ | ... |
| 模糊点  | ✅/❌ | ... |

### 改进建议（如果是 FAIL）
- ...
```
