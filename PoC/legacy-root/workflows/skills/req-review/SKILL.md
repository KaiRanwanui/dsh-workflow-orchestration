# 需求分析质量门禁

评审需求分析产出（analysis.md）的质量，输出 PASS/FAIL 判定。

## 检查项（均需满足）

1. 功能需求（FR）列表完整
2. 非功能需求（NFR）正确归类
3. 隐含假设已识别
4. 模糊点已标注
5. 无遗漏需求项

## 输出格式（gate-result 文件）

```markdown
# 门禁结果

判定: PASS    # 或 FAIL，5/5 通过即 PASS

## 检查明细
- [x] FR 完整
- [x] NFR 归类
- [x] 假设已识别
- [x] 模糊点已标注
- [x] 无遗漏

## 意见
（如有 FAIL 需说明具体问题）
```
