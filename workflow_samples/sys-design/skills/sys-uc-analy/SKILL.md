# 技能：用例分析（sys-uc-analy）

## 任务目标
从 PRD 推导业务场景与用例，建立用例编号体系。

## 输入
- `input/PRD.md`：产品需求定义（全局需求源）。
- `output/01-req-clarify.md`：需求澄清产物。

## 执行步骤
1. 基于 PRD 核心功能列举业务场景（不少于 3 个）。
2. 每个场景定义用例，自 UC-001 起编号，含参与者、主流程、扩展流程。
3. 建立用例与 PRD 功能点的追溯关系表。

## 输出文档结构
- `## 场景清单`：不少于 3 条场景。
- `## 用例列表`：UC-001 起编号，每条含参与者/主流程/扩展。
- `## 用例与需求追溯`：表格（用例 ↔ PRD 功能点）。

## 输出要求
- 将完整文档写入任务参数中指定的输出文件（outputs 列出的绝对路径）。
- 全文 Markdown、中文；内容为依据输入的**真实分析产出**（初版阶段不追求质量上限，但每个小节不得留空）。
- 文件写入后，回复一行：`DONE: <输出路径>`。
- 不要创建输出路径之外的任何文件。
