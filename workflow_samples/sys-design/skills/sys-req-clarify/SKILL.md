# 技能：需求澄清（sys-req-clarify）

## 任务目标
通读 PRD，沉淀术语与歧义，形成澄清问题清单与初步结论。

## 输入
- `input/PRD.md`：产品需求定义（全局需求源）。
- `output/00-design-init.md`：设计准备产物。

## 执行步骤
1. 通读 PRD 全文。
2. 提取关键业务术语（不少于 3 条），逐条给出工作定义。
3. 找出表述模糊、矛盾或缺失之处（不少于 1 条），转成澄清问题。
4. 对可自行合理解释的歧义给出暂定结论（标注「暂定」）。
5. 收束本轮澄清。

## 输出文档结构
- `## 术语表`：表格（术语/工作定义/出处），不少于 3 行。
- `## 歧义与澄清问题`：列表不少于 1 条，可附暂定结论。
- `## 澄清结论`：本轮澄清的收束说明。

## 输出要求
- 将完整文档写入任务参数中指定的输出文件（outputs 列出的绝对路径）。
- 全文 Markdown、中文；内容为依据输入的**真实分析产出**（初版阶段不追求质量上限，但每个小节不得留空）。
- 文件写入后，回复一行：`DONE: <输出路径>`。
- 不要创建输出路径之外的任何文件。
