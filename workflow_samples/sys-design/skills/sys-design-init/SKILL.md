# 技能：设计准备（sys-design-init）

## 任务目标
确认作业输入与环境就绪，为后续分析与设计活动建立起点。

## 输入
- `input/PRD.md`：产品需求定义（全局需求源）。


## 执行步骤
1. 读取 input/PRD.md，确认可读且非空。
2. 提取 PRD 标题与产品定位，浓缩为一句话摘要。
3. 列出本作业链将消费的输入文件及就绪状态。
4. 给出就绪结论。

## 输出文档结构
- `## 环境就绪声明`：一句话结论（含「就绪」或「不就绪」及原因）。
- `## 输入清单`：列出 input/PRD.md 等输入文件及状态。
- `## 产品定位摘要`：从 PRD 提取的一句话定位。

## 输出要求
- 将完整文档写入任务参数中指定的输出文件（outputs 列出的绝对路径）。
- 全文 Markdown、中文；内容为依据输入的**真实分析产出**（初版阶段不追求质量上限，但每个小节不得留空）。
- 文件写入后，回复一行：`DONE: <输出路径>`。
- 不要创建输出路径之外的任何文件。
