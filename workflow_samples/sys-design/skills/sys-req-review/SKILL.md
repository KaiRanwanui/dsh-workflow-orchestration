# 技能：需求评审（sys-req-review）

## 任务目标
对需求侧产物（00~05）做评审，形成意见与结论。

## 输入
- `input/PRD.md`：产品需求定义（全局需求源）。
- `output/05-sr-def.md`：SR 定义产物（评审主对象）。
- 上游 00~04 产物：按需回查。

## 执行步骤
1. 逐份检查 01~05 各产物：完整性、内部一致性、与 PRD 的对齐度。
2. 形成评审意见不少于 2 条，每条注明所针对的产物（文件名或活动名）。
3. 给出结论，明确二选一：通过 / 不通过。

## 输出文档结构
- `## 评审意见`：不少于 2 条，每条注明评审对象。
- `## 评审结论`：明确写「通过」或「不通过」。

## 输出要求
- 将完整文档写入任务参数中指定的输出文件（outputs 列出的绝对路径）。
- 全文 Markdown、中文；内容为依据输入的**真实分析产出**（初版阶段不追求质量上限，但每个小节不得留空）。
- 文件写入后，回复一行：`DONE: <输出路径>`。
- 不要创建输出路径之外的任何文件。
