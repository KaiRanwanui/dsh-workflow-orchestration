# 技能：设计基线（sys-design-baseline）

> 占位版（Iter-44 框架期）——只验证链路与文件衔接，不要求实质性内容质量。
> 实质方法论内容自 Iter-45 起充实。

## 任务目标
基于上游产物完成「设计基线」活动的占位文档，产出到本任务声明的输出文件。

## 执行步骤
1. 阅读本任务 inputs 列出的全部输入文件（含 PRD 与上游产物）。
2. 编写 Markdown 文档，标题《设计基线（占位）》，包含以下占位小节：
- `## 基线清单`（汇总本链全部产物的占位索引）
- `## 基线声明`
3. 每个小节写 1~2 句占位说明文字，说明该小节将来应承载的内容。

## 输出要求
- 将完整文档写入任务参数中指定的输出文件（outputs 列出的绝对路径）。
- 文件写入后，回复一行：`DONE: <输出路径>`。
- 不要创建输出路径之外的任何文件。
