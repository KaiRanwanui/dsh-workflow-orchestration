# 技能：SR 定义（sys-sr-def）

## 任务目标
汇总前序分析，产出条目化系统需求与追溯关系。

## 输入
- `input/PRD.md`：产品需求定义（全局需求源）。
- `output/03-func-impact.md`：功能影响分析产物。
- `output/04-dfx-analy.md`：DFX 分析产物。

## 执行步骤
1. 综合 PRD 与 func-impact、dfx-analy 产物，定义系统需求，自 SR-001 起编号（不少于 3 条），每条含描述、优先级、验收要点。
2. 建立追溯表：每条 SR 关联到 UC/F 编号或 DFX 约束。

## 输出文档结构
- `## 系统需求条目`：SR-001 起编号，不少于 3 条。
- `## 追溯关系`：表格（SR ↔ 上游编号）。

## 输出要求
- 将完整文档写入任务参数中指定的输出文件（outputs 列出的绝对路径）。
- 全文 Markdown、中文；内容为依据输入的**真实分析产出**（初版阶段不追求质量上限，但每个小节不得留空）。
- 文件写入后，回复一行：`DONE: <输出路径>`。
- 不要创建输出路径之外的任何文件。
