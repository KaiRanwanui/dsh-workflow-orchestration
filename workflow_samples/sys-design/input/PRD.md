# PRD：智能备忘录助手「快记」（示例需求）

> 阶段 5 框架验证用的极简产品需求定义样例（Iter-44 占位）。后续迭代将以真实 PRD 替换。

## 产品定位
面向个人用户的轻量备忘录应用，支持快速记录、分类检索与到期提醒。

## 核心功能
1. **快速记录**：一键新建笔记，支持文字与待办清单两种条目。
2. **分类与标签**：笔记可归入多个分类，可打任意标签。
3. **到期提醒**：待办条目可设截止时间，到期前推送提醒。

## 非功能要求
- 单机可用，数据本地存储。
- 移动端与桌面端 Web 适配。
- 记录操作 1 秒内完成响应。
